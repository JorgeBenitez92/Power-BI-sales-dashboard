# Power BI Sales Dashboard

Interactive multi-page Power BI report analyzing sales performance by product, region, and time — built as the capstone project of the Power BI module in a 224-hour Data Analytics Bootcamp (UVM/Ibaktor School).

## Español

**Contexto:** El reto integrador del módulo consistía en construir un dashboard de ventas completo aplicando, en un solo archivo, todo lo visto en el módulo: visualizaciones, medidas DAX, interactividad avanzada y diseño profesional.

**Qué hice:**
- Construí 3 páginas de reporte: Dashboard de Ventas, Crecimiento de Ventas y Detalles de Producto.
- Creé medidas DAX (agregaciones, medidas con contexto de filtro, inteligencia de tiempo, columnas calculadas).
- Configuré interactividad avanzada: segmentaciones sincronizadas, filtros a distintos niveles, **drill-through** entre páginas y **bookmarks** para navegación guiada.
- Apliqué un tema de colores personalizado (`Tema.json`) y buenas prácticas de diseño (jerarquía visual, formato condicional, accesibilidad).

**Herramientas:** Power BI Desktop, DAX, modelado de datos relacional.

**Archivos:**
- `Actividad Final.pbix` — el reporte completo (ábrelo con Power BI Desktop, gratuito).
- `Tema.json` — tema de colores personalizado usado en el reporte.

## English

**Context:** The module's capstone challenge was to build a complete sales dashboard in a single file, applying everything covered in the module: visualizations, DAX measures, advanced interactivity, and professional design.

**What I did:**
- Built a 3-page report: Sales Dashboard, Sales Growth, and Product Details.
- Created DAX measures (aggregations, filter-context measures, time intelligence, calculated columns).
- Configured advanced interactivity: synced slicers, multi-level filters, **drill-through** between pages, and **bookmarks** for guided navigation.
- Applied a custom color theme (`Tema.json`) and design best practices (visual hierarchy, conditional formatting, accessibility).

**Tools:** Power BI Desktop, DAX, relational data modeling.

**Files:**
- `Actividad Final.pbix` — the full report (open with Power BI Desktop, free to download).
- `Tema.json` — custom color theme used in the report.
